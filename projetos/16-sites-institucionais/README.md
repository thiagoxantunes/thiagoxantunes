> Sites desenvolvidos para clientes locais.

## O problema

Pequenos negócios e projetos culturais sem presença profissional na internet.

## O que o sistema faz

- **Cara da Rua** — Ponto de Cultura (oficinas de dança, música, teatro e Boi de Miracema), com oficinas gerenciadas pelo Supabase
- **Cine Miracema** — site do cinema da cidade
- **Nutricionista** — site profissional
- **Assessoria de Trânsito** — landing page do despachante com atendimento por WhatsApp
- **Psicóloga** — site profissional integrado ao sistema do consultório
- SEO local: meta tags, sitemap, robots

## Tecnologias

HTML · CSS · JavaScript · Supabase · Vercel

## Competências demonstradas

SEO local · Front-end · Atendimento a clientes
