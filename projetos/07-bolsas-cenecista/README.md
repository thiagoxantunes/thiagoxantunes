> Desenvolvido para o Colégio Cenecista, com **Clean Architecture**.

## O problema

O processo de bolsas envolvia muitos documentos em papel, fichas socioeconômicas e montagem manual de PDFs.

## O que o sistema faz

- Gestão de editais, pagamentos de inscrição e candidatos
- Ficha socioeconômica completa e gestão de documentos
- **OCR com Tesseract.js** para leitura de documentos
- **Montador de PDF** (pdf-lib) para juntar os documentos de cada candidato
- Emissão de declarações, coleta de assinaturas, análise e publicação do resultado
- Arquitetura em camadas (Clean Architecture) com RLS no Supabase

## Tecnologias

Next.js 16 · TypeScript · Tailwind 4 · shadcn/ui · Supabase · pdf-lib · Tesseract.js (OCR)

## Competências demonstradas
