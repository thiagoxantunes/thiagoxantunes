> Sistema sob medida para uma operação pecuária.

## O problema

Os dados de compras, produtores, fazendas, transporte e custos ficavam espalhados em planilhas diferentes, sem uma visão consolidada de resultado.

## O que o sistema faz

- Cadastro de produtores e fazendas com localização no mapa
- Operações de compra às quais tudo é vinculado: pesagem, fretes, ocorrências e custos
- Cálculos financeiros precisos com `decimal.js` e apuração de resultados
- Importação/exportação de planilhas (PapaParse, xlsx) com mapeamento das colunas antigas
- Tabelas avançadas, busca rápida (cmdk), permissões por perfil e recuperação de senha
- Documentação de arquitetura, modelo de dados, regras e integrações
