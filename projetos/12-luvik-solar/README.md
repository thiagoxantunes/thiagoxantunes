> Primeira versão de sistema comercial para o setor solar, antes do SolarOps Pro.

## O problema

Gerar orçamentos e faturas padronizados de forma rápida.

## O que o sistema faz

- Cadastro de clientes e produtos
- **Orçamentos** e **faturas** com geração de PDF (jsPDF + autotable)
- Dashboard com gráficos
- Upload de arquivos (drag and drop)

## Tecnologias

React · TypeScript · Vite · Zustand · Recharts · jsPDF

## Competências demonstradas

React SPA · Gerenciamento de estado · Geração de documentos
