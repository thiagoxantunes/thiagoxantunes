> Projeto pessoal.

## O problema

Ajudar pessoas (e famílias, com vários perfis) a manter a hidratação diária.

## O que o sistema faz

- Vários **perfis** por conta
- Registro de consumo com animações (Framer Motion)
- Histórico e gráficos por perfil
- Autenticação completa (cadastro, login, recuperação de senha)

## Tecnologias

Next.js · TypeScript · Supabase · Framer Motion · Recharts · Zustand

## Competências demonstradas

UX/animações · Multi-perfil
