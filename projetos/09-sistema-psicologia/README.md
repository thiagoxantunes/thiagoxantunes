> Desenvolvido para uma psicóloga de Miracema/RJ (site + sistema).

## O problema

Agenda, prontuários e pagamentos ficavam separados, e a profissional precisava também de presença online.

## O que o sistema faz

- Agenda e controle de **sessões**
- Cadastro de pacientes e **prontuário eletrônico**
- Financeiro: receitas, despesas e pagamentos pendentes
- Módulo de **IA** que auxilia na análise de registros (`/api/ia/analisar`)
- Notificações, relatórios e configurações
- **Site profissional** gerenciado pelo próprio sistema (deploy na Vercel)

## Tecnologias

Next.js · TypeScript · Supabase · Radix UI · React Hook Form · API de IA

## Competências demonstradas

Dados sensíveis/LGPD · IA aplicada · Sistemas para saúde
