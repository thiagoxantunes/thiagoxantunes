> Projeto para a loja Rei dos Barateiros — [instagram.com/reidosbarateiros](https://www.instagram.com/reidosbarateiros).

## O problema

A loja vendia só pelo Instagram e WhatsApp, sem um catálogo organizado com preços e detalhes.

## O que o sistema faz

- Vitrine com categorias, **busca**, carrossel e páginas de produto
- Botão **Comprar pelo WhatsApp** com mensagem pronta (produto, preço e link) via `wa.me`
- **Painel admin** para o lojista cadastrar produtos, categorias e imagens
- Imagens Open Graph geradas dinamicamente para compartilhamento
- Páginas institucionais (sobre, contato, privacidade), sitemap e robots

## Tecnologias

Next.js · React · Supabase · Embla Carousel

## Competências demonstradas
