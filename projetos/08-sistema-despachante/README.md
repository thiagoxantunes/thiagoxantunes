> Meu próprio negócio: **Thiago Antunes Assessoria de Trânsito**.

## O problema

Controlar clientes, veículos, serviços recorrentes (licenciamento, transferências) e financeiro sem depender de cadernos e planilhas.

## O que o sistema faz

- Cadastro de clientes e **veículos**, catálogo de serviços e busca global
- **Orçamentos** com geração de PDF e serviços **recorrentes** (ex.: licenciamento anual)
- Controle de contas e saídas, relatórios e exportação para Excel
- Integração com **WhatsApp** para atendimento
- Landing page pública com SEO (transferência, multas, licenciamento)
- Empacotado como **app Android** via Trusted Web Activity (Gradle)

## Tecnologias

Next.js · TypeScript · Supabase · Radix UI · jsPDF · xlsx · Android (Trusted Web Activity)

## Competências demonstradas

Produto próprio ponta a ponta · PWA/Android · Gestão financeira
